# Configuration

> **Privacy: check `text.fallback` if you use a local model.** With `text.backend = "ollama"` or `"openai"`, the
> default `text.fallback = "auto"` hands a failed request to the `claude` CLI when it is installed. The goal,
> field labels, and page excerpt then go to Anthropic. Set `text.fallback = "none"` to keep them local: a failed
> or unreachable backend then hands the miss back to your agent. See [backends.md](backends.md#fallback).

jev-browse works with **one required setting**, `TYPESAFE_API_KEY`. Everything else has a default. This page lists
every setting, where it can be set, and some common setups.

## Where settings come from

Highest priority first:

1. **Environment variables.** This includes the browser-harness agent-workspace `.env`
   (`~/.config/browser-harness/agent-workspace/.env` by default), which the harness loads into every
   `browser-harness` script. The shell's own environment wins over that file.
2. **The config file** (optional, TOML): `$JEV_BROWSE_CONFIG`, else `$XDG_CONFIG_HOME/jev-browse/config.toml`,
   else `~/.config/jev-browse/config.toml`. It is re-read when it changes.
3. **Built-in defaults.**

Per-call arguments (`fast_run(..., timeout_s=120, text_backend="none")`) win over all three.

Put **secrets only in the environment** (the harness `.env`, mode 600). The config file never supplies an API
key: a key-like entry there is reported as an unknown setting and ignored.

An invalid value (a word where a number belongs, an unknown backend name) never crashes a run. The setting keeps
its default, and `jev-browse doctor` reports the problem.

Check what is active:

```bash
python3 -m jev_browse config          # every setting, its value, and where it came from
python3 -m jev_browse doctor          # checks install, key, harness, text backend (+ canary), then a summary
python3 -m jev_browse config --example > ~/.config/jev-browse/config.toml   # a commented starting point
```

(`bin/jev-browse <command>` does the same from any directory; symlink it onto your `PATH` if you like.)

## Environment-only variables

| Variable | Meaning |
|---|---|
| `TYPESAFE_API_KEY` | TypeSafe API key (**required**). Keep it in the browser-harness agent-workspace `.env`. |
| `JEV_BROWSE_CONFIG` | Path of the config file. |
| `JEV_BROWSE_DISABLE` | `1` = the harness helpers are stubs that raise (jev-browse off, harness untouched). |
| `JEV_BROWSE_OWNER` | Tab-ownership tag. Set one per parallel agent (default: the Claude Code session id; `mcp-<random>` per `jev-browse mcp` server). |
| `JEV_BROWSE_OPENAI_API_KEY` | Default variable holding the `openai` backend's key (rename it with `openai.api_key_env`). |

## Common setups

**Zero config.** Set `TYPESAFE_API_KEY` and nothing else. If the `claude` CLI is on your `PATH` and logged in,
generated values come from your Claude subscription (Haiku). If it is not, misses hand back to you.

**Privacy mode: nothing goes to an LLM provider except TypeSafe.**

```toml
[text]
backend = "none"
```

Or pass `fast_run(..., text_backend="none")` for one run. Fields whose value is not in the goal then hand back
with `text_value_unavailable`, and you pass `values=`.

**A local model on Ollama, with no cloud fallback.**

```toml
[text]
backend = "ollama"
fallback = "none"          # a failed canary or an unreachable server hands the miss back to you

[ollama]
url = "http://127.0.0.1:11434"
model = "qwen3:30b-a3b"    # any model you have pulled; run bench/text_eval.py to check it first
# num_gpu = 0              # force CPU if your GPU path returns wrong answers (the canary catches that)
```

With the default `fallback = "auto"`, a failed or unreachable local backend falls back to the `claude` CLI when
it is installed. Your page text then goes to Anthropic. Set `fallback = "none"` if that is not what you want.

**An OpenAI-compatible endpoint** (OpenRouter, Groq, Cerebras, Gemini's OpenAI-compatible API, LM Studio,
llama.cpp, vLLM). Put the key in the harness `.env` under any name, and point `openai.api_key_env` at it:

```toml
[text]
backend = "openai"

[openai]
base_url = "https://openrouter.ai/api/v1"   # Groq: https://api.groq.com/openai/v1
                                            # Cerebras: https://api.cerebras.ai/v1
                                            # Gemini: https://generativelanguage.googleapis.com/v1beta/openai
model = "<a model id from your provider>"
api_key_env = "OPENROUTER_API_KEY"
```

The endpoint must accept `response_format: {"type": "json_object"}` on `/chat/completions`. The canary checks
three known answers before the backend is used. Run `bench/text_eval.py` against it to see its pass rate and
latency on the field cases (see [benchmarking.md](benchmarking.md)).

**Codex (ChatGPT subscription) instead of Claude.**

```toml
[text]
backend = "codex"

[codex]
model = "gpt-5.6-luna"
```

Needs the `codex` CLI logged in. This backend is **unmeasured** so far; see [backends.md](backends.md).

**Restrict jev-browse to some sites and tighten budgets.**

```toml
[safety]
allowed_hosts = ["en.wikipedia.org", "*.example.com"]

[run]
max_actions = 15
timeout_s = 60
```

`allowed_hosts` applies to every page jev-browse opens, adopts, or observes (a run that lands off-list hands back). It does not restrict
what you do with the harness directly.
